# 自助工具 3.5 批 · 验收标准

> 供 Ark 验收对照用。范围：PHQ-9 / GAD-7 自测（TOOL-03）、CBT 想法记录雏形（TOOL-05）；文案遵守 SEC-04（不诊断）。叠在第一～三批之上。不写业务实现说明。遵守 docs/adr/。量表中文版标注「演示 / 待心理中心确认」。

## 清单

- [ ] **PHQ-9、GAD-7：标准中文条目 + 计分；结果只展示分档 +「这不是诊断」**  
  条目与计分按标准中文版（本批为**演示**，正式授权待心理中心确认）。结果页**只**展示分档与非诊断说明，明确写「这不是诊断」（对齐 SEC-04）。  
  - PHQ-9 分档：0–4 / 5–9 / 10–14 / 15–19 / 20–27  
  - GAD-7 分档：0–4 / 5–9 / 10–14 / 15–21  
  **失败**：缺条目/计分错误、展示原始总分当诊断、无「这不是诊断」、分档边界与上表不符。

- [ ] **PHQ-9 第 9 题得分 > 0：立即展示危机支持话术**  
  第 9 题（自伤念头）任一选项得分 **> 0** 时，**立即**展示危机支持话术/卡片，对齐 COMP-04（固定话术 + 帮助资源配置的求助入口，不写死号码）。  
  **失败**：第 9 题 > 0 无危机话术，或话术依赖当次 AI 临场生成、号码写死。

- [ ] **CBT 想法记录雏形（TOOL-05）：可完成一轮记录与回看**  
  可走完引导式一轮（情境 → 自动想法 → 情绪强度 → 常见认知偏差勾选 → 替代想法 → 情绪再评分，允许等价精简）；仅本人可见；完成后可回看本轮/历史。  
  **失败**：无法完成一轮，或完成后无法回看。

- [ ] **量表本批只做学生自测，不入预警池**  
  量表结果**不**写入预警池、不触发 RISK-05 / Q3 入池逻辑（ADR 通过前）。学生侧自测可存可回看即可。  
  **失败**：自测结果进入预警池或触发辅导员侧量表预警。

## 非目标（本批不验）

- 量表入池新 ADR（RISK-05 / Q3）及入池实现  
- 学院范围权限 / 越权  
- 配置审计（ADM-05 等）  
- PHQ/GAD 中文版学校正式授权与分档文案定稿（文档注明「演示 / 待心理中心确认」即可，本批不阻塞演示验收）  
- 不冲第一～三批已列项；不要求后台展示敏感原文（ADR 0002）
