# 自助工具第一批 · 验收标准

> 给 Ark 验收对照用。范围：学生端自助工具面板（放松 / 释放 / 帮助）轻量修正，不扩 I2 新工具。遵守 docs/adr/（风险仍为消息级；求助资源脱敏与配置口径见 ADR 0002 / COMP-04）。不写业务实现说明。

## 清单

- [ ] **学业解压锦囊仅在「放松」页**  
  「放松」Tab 可见入口；「释放」「帮助」Tab **不得**再出现学业解压锦囊。

- [ ] **电子木鱼「今日」计数按日正确**  
  文案/数字表示**当日**敲击次数；跨自然日（设备本地日）归零重计；同日多次敲击累加；存储失败时当次仍可敲，不阻断操作。

- [ ] **打字发泄墙：写完再点释放后飘散**  
  输入区可先写完整段；**点击「释放」（或同等主按钮）后**文字才飘散/清空；未点释放前不应边打边散（自动清空）。

- [ ] **帮助页热线来自配置（非写死）**  
  「帮助」页号码/名称来自学校配置（如 scenario/context 或 ADM 配置源）；前端/仓库**不硬编码**真实热线号；未配置时有明确占位/提示，不展示虚构号码。

- [ ] **危机 / 红码消息后可一键进帮助或危机卡片**  
  学生发出触发 **red** 的消息并收到回复后：可见危机支持卡片，**或**提供一键进入「帮助」/求助资源的入口；yellow 不强制危机卡片（与 COMP-04 一致）。

## 非目标（本批不验）

- 不新增 TOOL-01～07 中尚未交付的工具形态  
- 不改风险分级规则与入池语义（ADR 0001）  
- 不要求工作台展示倾诉原文（ADR 0002）
