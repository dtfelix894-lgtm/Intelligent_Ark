# 智伴方舟高校版产品需求

## 定位

面向单所高校学生提供 AI 情绪陪伴，并为辅导员和心理中心提供脱敏风险预警与人工跟进工具。当前是本地功能验收版本，尚未完成真实环境试用验收；不声称绝对保密、医学诊断能力或多校数据隔离。阶段状态以 [交付规范](Delivery_Playbook.md) 为准。

## 用户与流程

- 学生以学号注册/登录（注册时可补充学校和学籍号），进入 `/chat` 与可选的“知心学姐/知心学长”对话。
- G 类高校管理员以工号登录 `/admin`，查看三张概览卡和待跟进预警，标记跟进后从待处理池移除。更详细的处置、趋势和活动查询目前主要是后端接口，不等于页面已有对应板块。
- 对话消息先落库，再生成回复和风险评估；黄色/红色事件进入预警池。

## 功能要求

1. 支持学业、就业、人际、情感和压力等高校场景。
2. 当前页面使用完整 JSON 回复、历史加载/失败重试和 ASR 语音回填。SSE、历史清除及 TTS 保留接口，不能据此宣称学生页面已有相应入口。SSE 为完整生成后分段发送。
3. 风险等级为 green / yellow / red，由有限关键词和片段排除规则产生；分值随命中标签数变化，不是固定三档量表。具体公式见 [技术规范](Tech_Spec.md)，边界见 [风险规则验收](Risk_Rule_Acceptance.md)。
4. 管理员查看脱敏摘要、标签并跟进；账号统计按注册学生而不是消息条数。默认约 3 秒轮询，可选 10/30 秒，跟进结果以数据库为准。
5. 高风险内容应提示联系辅导员、学校心理中心和现实中的可信任人员。
6. 保留每日治愈、能量补给电台、正念放松站、学业解压锦囊、情绪碎纸机、电子木鱼及打字发泄墙。天气与考试倒计时不在当前页面范围。
7. 右上角展示账户身份和相关设置；人设/管理偏好按账号保存在本浏览器，不跨设备同步。存储失败时本页仍生效并提示；工具累计计数仍是设备级。
8. 开场提示基于设备时间和月份推测，不是真实课表、考试安排或图书馆状态。

## 当前边界

绿色只表示本条规则未命中，不代表确认安全；复杂语义、跨轮上下文、历史和他人风险仍需人工判断。普通对话保存聊天历史，“正常不记录”当前仅指不新增风险事件；任何留存策略变更需另行确认。

ASR 已接入聊天输入区，识别内容先回填，由学生确认发送。真实录音依赖浏览器授权和安全上下文；本地替身验收不代表供应商/实体手机验收。TTS 缺少 `MIMO_API_KEY` 返回 502。LLM 无可用配置或异常时兜底，不能把兜底成功写成真实模型调用成功。

## 非功能要求

JWT 鉴权、角色守卫、SQLite WAL、CORS 配置、LLM 异常兜底、前端登录守卫和生产环境禁用 `dev_override`。

采用 `python scripts/verify_project.py` 隔离验证登录→对话→预警→跟进及异常恢复。公网证书、备份恢复、真实供应商、学校支持流程和目标设备属于 S4 发布门槛，未执行不得标为完成。
