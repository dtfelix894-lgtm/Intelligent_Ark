## 1. 产品概述

**智伴方舟**是一款融合生成式 AI 与场景感知技术的心理关怀与风险预警平台。系统采用 B2B2C 架构，面向两类机构（高校、社区）提供 SaaS 服务，每类机构均包含面向终端用户的 C 端应用与面向管理人员的 B 端大屏。

**核心商业价值：**
- 对机构（B端）：以 AI 替代人工的高频、低效巡查动作，实现风险的事前感知与免责留痕。
- 对用户（C端）：提供 7×24 小时的温暖 AI 陪伴，让用户在低门槛的对话中获得情绪支持。

---

## 2. 用户角色体系

系统实现了完整的三角色体系，每类角色有独立的认证入口与功能边界：

| 角色 | 标识符 | 认证入口 | 核心职责 |
|------|--------|----------|----------|
| **高校学生** | `student` | `/login` | 与 AI 进行心理陪伴对话 |
| **社区居民/老人** | `social` | `/login` | 与 AI 进行健康陪伴对话 |
| **高校管理员** | `admin` (G型) | `/admin-login` | 在大屏监控学生群体情绪风险 |
| **社区管理员** | `admin` (C型) | `/admin-login` | 在大屏监控社区老人健康风险 |

**账号约束：**
- C 端注册：学生填学号，社区居民填 QQ 邮箱。
- B 端注册：工号格式为 `G/C` + 3位数字（如 G001、C001），须持邀请码注册，邀请码由系统管理员线下分发。
- 演示账号：`001` / `123456`（学生），`002@qq.com` / `123456`（社区），`G001` / `123456`（高校管理员），`C001` / `123456`（社区管理员）。

## 4. C端功能模块（用户聊天界面）

**页面路由：`/chat`**

### 4.1 核心对话功能

- **F1 基础聊天交互：** 类微信气泡 UI，AI 消息逐字流式输出（SSE）。新消息自动滚动至底部，有"AI 正在输入..."状态提示。
- **F2 场景自适应问候：** 首条消息根据当前北京时间（凌晨/上午/下午/晚上）和场景（高校/社区）自动生成不同问候语。
- **F3 快捷回复按钮：** 根据场景提供预设快捷语（高校3条，社区8条），一键发送。
- **F4 实时风险评估（后台静默）：** 每次对话调用 AI 时，后端同时返回 `risk_assessment`（level/score/tags/summary），C 端不向用户展示，但会将 yellow/red 事件写入 localStorage 供 B 端大屏感知。

### 4.2 开发者路演面板（Dev Panel）

- **入口：** 连续点击 AI 头像 3 次（3秒内），底部弹出控制台。
- **功能：** 4 个按钮：正常聊天 / 注入黄码（失眠焦虑）/ 注入红码（轻生危机）/ 重置系统。
- **后端联动：** Dev Panel 发送 `dev_override` 参数到后端，后端跳过 LLM 调用直接返回对应预设剧本，保证路演稳定。
- **仅限开发环境：** `APP_ENV=prod` 时后端拒绝 `dev_override` 请求。

### 4.3 高校专属模块

| 功能 | 描述 |
|------|------|
| **侧边栏（Left Panel）** | 展示今日天气、考研/考试倒计时、每日励志一句话、校园心理热线 |
| **右侧面板（Right Panel）** | 更多资源与工具入口 |
| **能量补给电台** | 内置音乐播放器，预置《勋章》《Lemon Tree》《钢琴纯音》等曲目 |
| **解压锦囊** | 弹窗展示呼吸调节/身体活动/情绪记录/生活小确幸四类减压技巧 |
| **赛博解压游戏** | 木鱼敲击（muyu）、气泡戳戳（bubble）小游戏 |

### 4.4 社区专属模块

| 功能 | 描述 |
|------|------|
| **侧边栏（Left Panel）** | 展示今日天气/日期/星期、服药/散步/作息日程提醒、社区急救热线 |
| **字号缩放** | 4 档（0.9×/1.0×/1.15×/1.3×），默认 1.15× |
| **称呼偏好** | 首次使用引导选择"爷爷"或"奶奶"，AI 后续回复中统一使用 |
| **TTS 朗读** | 每条 AI 回复旁有朗读按钮，调用浏览器 SpeechSynthesis API |
| **语音输入** | 微信风格"按住说话"，录制 WAV 格式上传后端 `/api/asr/transcribe` 识别为文字 |
| **SOS 紧急求助** | 底部一键展开 SOS 面板，显示急救电话和家人电话 |
| **老友收音机** | 内置京剧/评书/健康知识三个频道 |
| **消息定时提醒** | 特定时间节点的服药/健康提示，到时在对话流中插入提示卡片 |
| **家人电话绑定** | 用户可填写家人电话，显示在 SOS 面板 |

## 5. B端功能模块（管理员大屏）

**页面路由：`/admin`**（需管理员身份登录）

### 5.1 数据概览

顶部 Stats Bar 展示：监控总人数 / 今日红码数 / 今日黄码数。数据根据管理员类型（G/C）加载对应场景的 Mock 统计数据。

### 5.2 实时预警工单池

- 从后端 `/api/admin/alerts` 拉取数据库中持久化的风险事件。
- 同时监听 localStorage `latest_ark_alert` 事件，实现跨 Tab 实时推送。
- 卡片按风险级别色标展示（红/黄/绿），显示 AI 脱敏摘要，**绝对不展示原始聊天内容**。
- 点击卡片在右侧操作台展示详情。

### 5.3 群体情绪可视化（Recharts）

- **折线图：** 本周整体风险指数走势（7天）。
- **饼图：** 高频风险标签分布（考研压力/失眠焦虑等）。
- 两套数据集随场景切换（G型管理员看高校数据，C型看社区数据）。

### 5.4 干预闭环操作台

- 选中工单后，右侧展示：脱敏摘要、风险标签、评分。
- 两个干预动作按钮（随场景变化）：
  - 高校：`联系学生/辅导员` + `转介心理中心`
  - 社区：`呼叫紧急联系人` + `派发网格员上门`
- 底部 `标记安全并结案` 按钮：调用 `/api/admin/alerts/{id}/handle`，将事件标记为已处理，卡片变灰归档。

## 6. 认证与登录流程

### C端登录（`/login`）

1. 学号登录（角色：student）或 QQ 邮箱登录（角色：social）。
2. 支持注册：学生需填学号/学校/学历；社区居民需填 QQ 邮箱。
3. 登录成功后 JWT Token 存入 localStorage，后续请求以 `Authorization: Bearer <token>` 头携带。

### B端登录（`/admin-login`）

1. 工号/密码登录，登录响应中包含 `admin_type`（G/C）和 `school_name`。
2. 支持注册：须填写邀请码（由 `ADMIN_INVITE_CODE` 环境变量控制）。
3. 含滑块验证码（SliderCaptcha），防机器登录。
4. 登录成功后 Token 写入 Cookie（HttpOnly，7天有效）。

## 7. 核心数据流转路径

### 正常对话（C端 → LLM → B端）

```
用户发消息（/chat）
  → POST /api/chat/stream（携带 JWT）
    → 后端持久化 user 消息
    → 调用智谱 GLM-4 / glm-4.7（JSON模式）
    → 返回 {reply, risk_assessment}
    → 持久化 assistant 消息
    → yellow/red 时保存 risk_events 记录
  ← 前端收到响应，渲染气泡
  → 若 level=yellow/red，写入 localStorage('latest_ark_alert')
  → B端大屏监听 StorageEvent，立即更新预警列表
  → B端也可通过 GET /api/admin/alerts 拉取持久化记录
```

### 社区模式流式对话（SSE）

```
前端 EventSource 连接 POST /api/chat/stream-sse
  → 服务端逐 token yield {"type":"delta","content":"..."}
  → 完整回复后 yield {"type":"done","reply":"...","risk_assessment":{...}}
  → 前端逐字显示（适合老人阅读速度）
```

### 语音输入流程

```
用户按住说话按钮
  → Web Audio API 采集 PCM（WAV 封包）
  → 抬手后 POST /api/asr/transcribe（multipart，WAV格式）
  → 智谱 glm-asr 转写为文本
  → 前端将文本填入输入框并自动发送
```

### Dev Panel 路演流程

```
评委点击 [注入红码] 按钮
  → 前端携带 dev_override:"red_alert" 调用后端
  → 后端跳过 LLM，直接返回预设剧本 JSON（level=red,score=95）
  → 前端写 localStorage
  → B端大屏立即弹出红色预警卡片
```

## 8. 非功能性需求

| 类别 | 要求 |
|------|------|
| **安全** | JWT 鉴权（HS256），生产环境 `JWT_SECRET` ≥ 32位，密码 bcrypt 存储，HttpOnly Cookie |
| **隐私** | 预警大屏只展示 AI 生成的脱敏摘要，禁止暴露原始对话内容 |
| **稳定性** | In-flight 请求去重（5秒窗口防双击重复消耗 Token）；LLM 异常时关键词兜底返回预设剧本 |
| **可访问性** | 社区模式字号可缩放；TTS 朗读支持；大字体友好布局 |
| **演示稳定** | Dev Panel 预设剧本绕过 LLM，保证路演 100% 成功触发预警 |
| **部署灵活** | CORS 正则匹配任意 host/IP，支持局域网演示；`ALLOWED_ORIGINS` 环境变量精确控制 |
