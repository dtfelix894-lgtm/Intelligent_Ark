> **用途：** 挑战杯创业赛终审答辩 PPT 逐页策划方案（设计计划，非成品 PPT）。

## ⛔ 本次硬性赛规（设计的第一约束）

| 约束 | 数值 | 对设计的影响 |
|------|------|--------------|
| 总答辩时间 | ≤ **8 分钟** | — |
| **陈述时间** | **≤ 5 分钟（严控）** | **最关键**：实际只能讲 15–16 页，每页平均 ~18 秒 |
| 答辩问答 | ≤ 3 分钟 | 见附录 A 应答锦囊，每题一句话 |
| PPT 比例 | **16:9** | 所有版式按 16:9 设计 |
| PPT 页数 | ≤ **22 页** | 我们用 **16 页**——5 分钟讲不完 22 页，少即是多 |
| 文件大小 | ≤ **100 M** | 视频压缩 + 图片压缩，见 §制作规范 |
| 视频 | 建议 **MP4**，**必须嵌入幻灯片**，禁止单独存放/超链接 | Demo 改为**嵌入式 MP4 录屏**，不做现场切 Tab |
| 设备 | **Office 2016** + PotPlayer | 字体/视频编码必须兼容，见 §制作规范 |

> **核心判断：** 5 分钟是真正的瓶颈，不是 22 页。**页数砍到 16 页是刻意为之**——给每页留足讲述时间，避免翻页如飞、评委没看清。

## 0. 设计总则

### 0.1 叙事主线（一句话贯穿）

> **「AI 在前台做温暖陪伴，在后台做静默风险预警，把有限人力精准送到最需要的人身边。」**

评委思考链 = 页面顺序：**为什么做 → 做了什么 → 谁来做 → 能否赚钱。**

### 0.2 视觉规范

| 维度 | 规范 | 备注（适配考场设备） |
|------|------|----------------------|
| 主色 | 治愈蓝绿 `#2BB3A3` + 深海蓝 `#1E3A5F` | 心理/健康/安全感调性 |
| 风险三色 | green `#3DBE7B` / yellow `#F5A623` / red `#E5484D` | 全场统一，形成记忆点 |
| 背景/正文 | 浅底 `#F7FAF9` / 深字 `#2D3340` | 投影仪友好 |
| **字体** | **微软雅黑（标题 Bold / 正文 Regular）** | ⚠ **不要用思源黑体**——考场 Office 2016 可能没装，会乱码。微软雅黑全 Windows 自带；若要特殊字体，**必须嵌入字体**（见 §制作规范） |
| 字号 | 标题 ≥32pt，正文 ≥20pt，数据数字超大号 | 后排评委要看清 |
| 风格 | 圆角卡片 + 大留白 + 弱阴影 | 呼应产品前端质感 |

### 0.3 每页原则

- 一页一观点，**标题即结论**（直接写结论，不写"关于…的介绍"）。
- 正文 ≤ 5 行；能用图/表/数字就不堆字。
- 每页一个"口播锚点"——主讲只需记一句话。

# 逐页设计（16 页）

### P1 · 封面（8s）

- **标题：** 智伴方舟 Intelligent Ark
- **副标题：** B2B2C 心理关怀与风险预警平台 · 一模两用双轨架构
- **Slogan：** 「让每一次倾诉都被听见，让每一个风险都被看见」
- **视觉：** 中央 Logo（舟 + 对话气泡/心电波）；底部：团队名 + 赛道 + 日期。主色渐变背景。
- **口播：** "各位评委好，我们是智伴方舟——（念 Slogan）。"
- **来源：** `README.md`。

### P2 · 双群体痛点（30s）

- **标题：** 两个沉默群体，同一种困境——有情绪，没人接得住
- **文案（左右双栏）：**
  - **高校学生**：1 名心理咨询师 : **4000+ 学生**；主动求助率 **<10%**。
  - **独居老人**：60 岁以上 **超 3 亿**，独居/空巢 **超 1.3 亿**；网格员人均 **300–500 户**，难高频入户。
- **视觉：** 左蓝（校园）右暖（社区），各一个超大数字 + 小人图标阵列示意比例失衡。
- **口播：** "一边是不敢说的学生，一边是没人问的老人——需求高频、人力极缺、发现太晚。"
- **来源：** `挑战杯终审答辩准备.md` §1.2。⚠ 数据标注年份与出处。

### P3 · 政策红利 + 市场空白（25s，合并原 P4+P5）

- **标题：** 政策在催，但市面上"会预警的陪伴"还是空白
- **文案：**
  - **政策**：教育部 2024《高校学生心理健康工作质量提升行动方案》——"预防-预警-干预"三级体系（硬指标）；民政部"智慧养老" + 政府购买社会服务。
  - **空白（2×2 象限）**：纯心理 App = 有陪伴无预警；智能硬件 = 有监测无温度；通用大模型 = 有对话无闭环；**智伴方舟 = 陪伴+预警+闭环（独占右上角）**。
- **视觉：** 上半政策时间轴（2 个印章卡片），下半 2×2 象限图，我们独占右上。
- **口播：** "政策把'预警'写成了硬考核，但市场只有聊天机器人——能在后台发现风险并递到管理者手里的，没有。这就是我们补的空白。"
- **来源：** `挑战杯终审答辩准备.md` §1.2/§1.3/§Q1。

### P4 · 产品定位：一模两用（22s）

- **标题：** 一套系统，服务两个万亿级民生赛道
- **文案：**
  - 不是"做一个心理咨询 App"，而是**连接 C 端用户与 B 端管理者的"风险感知中枢"**。
  - **B2B2C**：向机构卖 SaaS，机构服务终端用户。一套架构 → 两个市场，**边际成本极低**。
- **视觉：** 中央"方舟"核心，左右两条轨道分出"高校 / 社区"，各挂 C 端 + B 端图标，强调"同一引擎"。
- **口播：** "记住四个字——一模两用。同一个 AI 引擎，换人设和议题，就从大学生切到独居老人。"
- **来源：** `PRD.md` §1、`README.md`。

### P5 · 双轨场景对照（20s）

- **标题：** 知心学姐 × 社区小暖——同一内核，两种温度
- **文案（精简表）：**

| | 高校 | 社区 |
|---|---|---|
| 用户 | 压力大学生 | 独居老人 60–90 岁 |
| 人设 | 知心学姐（可用网络用语） | 社区小暖（慢速、像晚辈） |
| 议题 | 考研/就业/人际/经济 | 健康/服药/跌倒/孤独 |
| 热线 | 心理援助 400-161-9995 | 急救 120 + 社区 12345 |

- **视觉：** 双人设头像卡置顶 + 对照表，两侧蓝/暖底色。
- **口播：** "同一句'最近睡不好'，学姐陪你聊考研焦虑，小暖关心你身体、提醒家人——这就是场景化的价值。"
- **来源：** `PRD.md` §3。

### P6 · 核心闭环：发现→预警→干预→结案（28s，重点页）

- **标题：** 我们卖的不是聊天机器人，是一条"风险处置流水线"
- **文案（四步）：**
  1. **发现**：每轮对话后台静默生成三级风险评分（C 端无感）。
  2. **预警**：yellow/red → 落库 + 实时推送 B 端大屏。
  3. **干预**：管理员看**脱敏摘要**，一键联系/呼叫/派单。
  4. **结案**：标记安全归档，可留痕、可追溯、可免责。
- **视觉：** 横向四步流程图，配色随等级升级（绿→黄→红→灰）；中间一条"C 端无感 / B 端可见"分隔线突出隐私边界。
- **口播：** "别人停在'聊'，我们走完'聊→预警→干预→结案'——这是根本区别。"
- **来源：** `PRD.md` §5、`Tech_Spec.md` §5.4。

### P7 · C 端体验（高校 + 社区，双栏，25s）

- **标题：** 对学生降门槛，对老人零门槛
- **文案（左右双栏）：**
  - **高校**：流式气泡对话、场景化问候、侧边栏（天气/考研倒计时/励志/心理热线）、解压电台与小游戏。
  - **社区·适老化**：4 档字号、TTS 朗读、微信式"按住说话"语音（glm-asr）、SOS 一键求助、定时服药提醒。
- **视觉：** 左右各一张高保真界面截图（**占位**，定稿前实跑回填），各标 2 个亮点。
- **口播：** "学生端不预约、不评判、不泄露；老人端只要会按住说话就能用——这是技术平权。"
- **来源：** `PRD.md` §4.1/4.3/4.4。

### P8 · B 端管理大屏（20s）

- **标题：** 管理者的一块屏：从"主动巡查"到"被动接警"
- **文案：**
  - 实时预警工单池（红/黄/绿色标），**只显脱敏摘要，绝不显原始聊天**。
  - 群体情绪可视化（风险走势折线 + 高频标签饼图）。
  - 干预操作台：摘要 + 标签 + 评分 + 干预动作 + "标记安全并结案"。
- **视觉：** 大屏截图（**占位**），圈出脱敏摘要区突出隐私设计。
- **口播：** "管理员不再大海捞针，精力只花在系统标红的人身上——这是效率革命。"
- **来源：** `PRD.md` §5。群体可视化当前为 Mock，被问按附录 A-Q6。

### P9 · 嵌入式 Demo 视频（MP4 ≤40s，最具说服力）

- **标题：** 现场演示：从一句"我不想活了"到管理员介入，只需几秒
- **内容：** 本页**嵌入一段 ≤40 秒 MP4 录屏**（非现场切 Tab），脚本：
  1. C 端正常聊天（5s，展示 AI 温度）。
  2. 连点头像 3 次 → Dev Panel → 注入红码（10s）。
  3. B 端大屏顶部**秒级弹红色预警** → 点开脱敏摘要 → "标记安全并结案"（20s）。
- **视觉：** 视频铺满版面（16:9），左上角小标题。**不留长文字**，让视频说话。
- **口播：** "请看真实系统——（播放）注意管理端，预警秒级弹出，点开是脱敏摘要，一键结案，闭环完成。"

### P10 · 技术壁垒：五道工程护城河（22s）

# §制作规范（考场设备兼容 + 控大小，务必照做）

### 视频（P9 Demo）

- **格式/编码**：MP4 **H.264 视频 + AAC 音频**（Office 2016 + PotPlayer 最稳兼容）。
- **嵌入方式**：PowerPoint 2016 → 插入 → 视频 → **此设备上的视频**（默认嵌入，不是链接）。**禁止**插入超链接或外部文件引用。插入后用 "文件 → 信息 → 检查是否有链接的视频" 确认已嵌入。
- **时长 ≤ 40 秒**、**分辨率 1080p 或 720p**、**码率 4–8 Mbps** → 单段约 20–50M，整包可控在 100M 内。
- **压缩**：若超大，用 PowerPoint "文件 → 压缩媒体 → 全高清/HD" 或 HandBrake 重压。
- **设置**：视频设为"单击时/自动"播放，建议手动单击，避免翻到就播打乱节奏。

### 字体

- 优先 **微软雅黑**（考场必有）。若用其他字体，**必须嵌入**：文件 → 选项 → 保存 → 勾选 "将字体嵌入文件（仅嵌入演示文稿中使用的字符）"。否则考场 Office 2016 缺字体会乱码/错位。

### 文件大小（≤100M）

- 图片统一压缩：文件 → 压缩图片 → 220ppi（去掉裁剪区域）。
- 截图存 **PNG/JPG** 适度压缩，避免逐张超 2M。
