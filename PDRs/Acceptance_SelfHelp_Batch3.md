# 自助工具第三批 · 验收标准

> 供 Ark 验收对照用。范围：情境推荐置顶、情绪打卡与近 7 日趋势、电台 UI 曲目合规复核。叠在第一批 / 第二批之上。不写业务实现说明。遵守 docs/adr/。风险仅为信息展示，不要求后台展示原文。

## 清单

- [ ] **情境推荐：信号下自助侧栏置顶对应工具，可见变化**  
  在「睡不着 / 考试 / 想哭」等情境信号下，自助侧栏**置顶**对应工具（或等价显眼推荐位），用户可**肉眼看到**排序/推荐相对默认态的变化。  
  **失败**：信号已触发但侧栏无置顶/无可见差异。

- [ ] **情绪打卡：每日可记 + 近 7 日趋势可见**  
  用户当日可完成一次（或约定次数内）情绪打卡并成功保存；界面可查看**近 7 日**情绪趋势（图表或等价列表均可）。  
  **失败**：无法打卡、无法保存，或近 7 日趋势入口/数据不可见。

- [ ] **电台 UI 无商业风险曲（lemon-tree / medal 等不出现）**  
  电台曲库与播放列表 UI 中**不出现** lemon-tree、medal 等已知商业风险曲目名称或入口（与第二批曲库合规一致，本批复核 UI 层）。  
  **失败**：UI 仍展示上述或同类未授权商业曲目。

## 非目标（本批不验）

- **PHQ-9 / GAD-7 / CBT 栎举**划为 3.5 / 第四批，**本批不覆盖、不验收**。
- 不冲第一批 / 第二批已列验收项（放松 Tab、木鱼按日、发泄墙、热线配置、危机一键、曲库来源标注、播放控件、雨声体积、正念倒计时、可视化呼吸等）。
- 核心风险分级调参（ADR 0001）；不要求后台展示敏感原文（ADR 0002）。
