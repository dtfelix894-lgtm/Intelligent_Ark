# 自助工具第二批 · 验收标准

> 给 Ark 验收对照用。范围：能量补给电台、正念放松站、学业解压锦囊「呼吸调节」轻量补齐（对齐 PRD_v2 TOOL-04 可视化呼吸引导口径）。叠在第一批之上；不写业务实现说明。遵守 docs/adr/（风险仍为消息级；不要求工作台展示原文）。

## 清单

- [ ] **电台曲库合规（无商业风险；来源可查/已标注）**  
  曲目/音效可商用或已获授权/公有域；仓库或界面有**来源标注**（链接或许可证说明）可查；不含明显侵权/未授权商业曲目。  
  **失败**：出现无来源标注的商业流行曲，或无法说明授权依据。

- [ ] **进度条 / 音量 / 定时关闭（15/30）可用**  
  播放中进度条可拖或可点跳转；音量可调且即时生效；定时关闭提供 **15 分钟**与 **30 分钟**选项，到时自动停播（或进入静音停播态），不崩溃。  
  **失败**：任一项缺失、不可操作，或定时到点不停。

- [ ] **雨声音频体积移动端可接受**  
  雨声（或等价环境音）单文件体积适合移动端加载（建议单曲 **≤ ~2MB**，或以弱网下可在数秒内起播为准）；过大须有压缩/替代方案说明。  
  **失败**：弱网或真机明显长时间白等、流量异常偏大且无说明。

- [ ] **正念 1 / 3 / 5 分钟：倒计时 + 呼吸引导可完成一轮**  
  可选 1、3、5 分钟；启动后倒计时可见且准确走完；期间有呼吸节奏引导；用户可完整完成一轮（含自然结束），异常退出不卡死。  
  **失败**：缺任一时长、倒计时不准/卡住，或无法走完一轮。

- [ ] **锦囊「呼吸调节」为可视化引导（非纯文案）**  
  学业解压锦囊中的「呼吸调节」须有**可视化**节奏引导（动画/图形节拍等），非仅静态文字说明；可暂停或可退出。  
  **失败**：只有纯文案步骤、无可视节奏。
