# 高校风险表达规则验收（S3-05）

## 目的与边界

本规范约束现有关键词分级、回复及工作台入池行为，不新增诊疗功能。合成样例通过只表示实现符合产品约定，不表示临床有效性、诊断能力或真实人群准确率；绿色只表示本条规则未命中，绝不是“已确认安全”。发布前仍需学校心理支持人员审核误报/漏报风险。

当前按单条消息、有限中文关键词判断，不解析完整语义或跨轮风险演变。现有历史预警不会因为下一条绿色消息被撤销，跟进仍由工作人员处理。分值是规则排序权重，不是患病概率或医学量表。

## 处理约定

| 场景 | 例子 | 预期行为 |
| --- | --- | --- |
| 明确本人风险 | 我不想活了 / 我想伤害自己 | 红色，保留现实支持建议并入池 |
| 完整明确否定 | 我没有自杀的想法 / 我不会伤害自己 | 此单独句不因该词入池；不代表已排除真实风险 |
| 否定后有风险 | 我不想自杀，但我想伤害自己 | 红色；否定不覆盖后续句 |
| 双重否定、犹豫 | 我不是不想自杀 / 我不敢自杀 | 红色；不当作明确安全表态 |
| 本人/裸引用 | 我脑子里一直是“我不想活了” / “我不想活了” | 红色；引号本身不豁免 |
| 完整虚构引用 | 小说里的人物说“我不想活了” | 只排除此边界明确的完整引用句 |
| 虚构加本人风险 | 小说里的人物说“我不想活了”，我也想伤害自己 | 红色；不能因为包含“小说”而整条忽略 |
| 明确教学主题 | 今天心理课讨论自杀预防 / 我在写关于自杀预防的论文 | 有限完整句式不因教学主题入池 |
| 教学中的真实表达 | 心理课上我说我想自杀 | 红色；课堂不是豁免条件 |
| 现实他人求助 | 室友说“我不想活了”，我该怎么办 | 保留红色信号，但摘要明确对象待核实，不断言学生本人有意图 |
| 历史/不确定信息 | 我以前自残过 / 新闻提到自杀，我不知道怎么办 | 暂保留信号，人工核实；已知会有误报 |
| 否定情绪/双重否定 | 我并不焦虑 / 我不是不焦虑 | 分别绿色/黄色 |
| 黄色不同困扰 | 我好难过 / 最近学习压力很大 / 最近睡不着 | 黄色；回复不添加未表达的症状或持续时间 |

完整可执行清单位于 `backend/test_risk_language.py` 的 `CASES`（35 条）。新增排除规则必须同时增加混合句、转折句、双重否定或现实求助的保留用例，禁止仅删除风险关键词以让误报测试通过。标点、转折先划分片段；排除条件使用完整片段匹配，而非整条消息的宽泛包含匹配。

## 回复与数据一致性

- 黄色兜底采用不虚构症状的支持性问句，并建议在困扰持续或影响生活时寻求现实支持。
- 模型提示词明确规则等级和标签，要求不虚构症状/持续时间，不把他人经历归给本人；真实供应商是否始终遵循仍待实调。
- 模型回复与兜底均由同一 `_risk` 生成等级；不是让模型文字直接决定入池。
- 红色摘要仅陈述消息含有安全信号、对象及当前状态待人工核实，不复制聊天原文。
- `test_contracts.py` 使用内存数据库和真实 API handlers，35 条消息逐次校验预警数、等级及注册学生计数；非绿色才新增预警。普通聊天历史沿用既有保存策略，不等同于“完全不留存”。

## 参考资料与限制

[NIMH 自杀预防常见问题](https://www.nimh.nih.gov/health/publications/suicide-faq)强调认真对待现实中的相关表达；[支持性应对步骤](https://www.nimh.nih.gov/health/publications/5-action-steps-to-help-someone-having-thoughts-of-suicide)提供现实支持方向。这些资料不是本项目三色阈值、中文正则或分值的验证依据，也没有授权将工程测试视为医学验证。项目不照搬美国紧急联系电话。

已知不足：隐喻、方言、错别字、跨轮指代、第三方对象归属、复杂引号及历史风险时态仍可能误判。现有结构没有单独的“他人风险”实体，暂在当前提交者关联记录中保留信号并标注对象待核实；不得用它认定学生本人存在某种疾病或用于自动惩戒。扩大判断能力或改变留存策略需另立任务审核。
