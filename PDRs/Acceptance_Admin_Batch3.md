# 管理员端第三批 · 验收标准

> 供 Ark 验收团队用。范围：预警池 **跟进状态机雏形** + **跟进记录（备注）** + **复评提醒雏形** + **结案与结案标注** + 兼容第①②批。对齐 PRD_v2 CASE-01/02/03/04 **可落地子集**（非完整 I1 全状态边）；脱敏遵守 ADR 0002。只写验收，不写业务实现说明。

## 与 handled / legacy 兼容映射（本批必写清）

| 现网 / 第①批口径 | 本批状态机口径 | 说明 |
| --- | --- | --- |
| 待跟进（handled=false） | 状态 ≠ closed | 预警池「待跟进」视图 = 未结案事件（与 PRD 5.2 / GLOSSARY 一致） |
| 已跟进（handled=true） | 状态 = closed | 结案后进入「已跟进」/离开待跟进 |
| POST .../handle（action=follow_up） | 任意未结案 → closed，标注 legacy_unlabeled（页显「未标注」） | 快速结案兼容边；**新页面不以之为主按钮**，但接口须保留且幂等（CASE-01 兼容） |
| 第②批「认领」后可见负责人 | pending → claimed（或已认领保持 claimed） | 认领/分派不破坏本批流转；改派非状态变化 |

本批**至少**支持并在工作台可见的状态子集：pending / claimed → intervening / monitoring → closed。verifying / referred 可暂不落地，但不得与上表冲突；若未做须在实现备注标明。

## 清单

- [ ] **跟进状态机雏形：可见当前状态并可合法流转**  
  详情/列表展示当前状态（中文标签；存储英文枚举）。至少支持合法路径：pending/claimed → intervening 或 monitoring → closed（可经认领进入 claimed）。工作台可触发流转并刷新后保持。非法跳步（如本批未开放的 pending → intervening，或 closed → monitoring）须拒绝（建议 409）且不写脏状态。每次成功流转宜留不可改流转痕迹（谁、何时、从哪到哪）；若排期紧可先保证状态字段正确，但不得静默丢状态。  
  **失败**：无状态展示；只能「已跟进」二值、无法进 intervening/monitoring；非法流转成功；刷新后状态回退。

- [ ] **跟进记录：可新增备注类记录，详情可回看列表（无消息原文）**  
  在已认领及之后的未结案状态下，可追加至少一类「备注/其他」跟进记录（有发生时间或写入时间、简要说明；限长建议 ≤500 字）。记录**只追加不删改**；详情中可见按时间排列的列表。页面提示勿粘贴学生原话。列表与说明中**不得**出现学生消息原文（ADR 0002 / CASE-02 子集）。完整类型枚举（约谈/电话/家访/转介等）与 referred 推进为尽量验，备注类为必验。  
  **失败**：无法新增；详情看不到历史；可改删旧记录；出现原文。

- [ ] **复评提醒雏形：结案或进入 monitoring 可设复评；工作台可见到期/逾期；可完成一次复评登记**  
  事件进入 monitoring，或结案（建议「确认风险」类标注）时，可设定至少一次复评日期（可用默认天数，如 14，不必一次做满 14+30）。工作台有「今日到期 / 已逾期」**数量或列表入口**（站内即可，不发站外）。可完成一次复评登记：写一条复评类跟进（或等价记录）并选结果（至少：好转 / 仍有风险）；「仍有风险」时 monitoring 回到 intervening（已结案重开本批可不做全量，有则注明）。对齐 CASE-03 子集。  
  **失败**：无处设复评；工作台无到期/逾期入口；无法登记复评结果；登记后状态该变不变。

- [ ] **结案：可选简单结案标注；结案后离开待跟进视图**  
  可主动结案进入 closed；结案时至少能选简单标注之一：**确认风险 / 误报 / 无法判断**（或与 legacy 兼容：经 handle 走 legacy_unlabeled「未标注」）。结案后该事件从「待跟进」视图移除，出现在「已跟进」或等价已结案视图；刷新保持。结案说明限长即可；「风险对象为他人」勾选本批尽量验。对齐 CASE-04 子集 + CASE-01 兼容边。  
  **失败**：无法结案；结案后仍留在待跟进；无任何标注口径（含 legacy）；handle 快速结案回归失败。

- [ ] **兼容第①②批：认领/分派/筛选/handle 不回归；学生端黄红入池不变**  
  第①批：等级筛选（黄/红/全部）、待跟进/已跟进、红色优先、概览 stats/trend/tags、标记跟进 POST .../handle（action=follow_up）仍可用且语义符合上表映射。第②批：脱敏详情、学生分组（不去重）、认领（必）、分派（若已做）不回归。学生端 yellow/red 入池字段与工作台一致；green 不入池。  
  **失败**：旧筛选/跟进/认领不可用；handle 幂等或 legacy 标注被破坏；入池联通断裂；详情出现原文。

## 本批不做（范围外）

- 超时升级全量（POOL-02：升级计时/通知全链路）
- 配置页 ADM-03；工作人员子角色精细权限 ADM-01；学院范围 POOL-06
- 量表入预警池（RISK-05 / 待 ADR）
- 完整审计日志页 ADM-05（本批仅状态流转/打开详情「有则写」即可）
- 完整 5.2 全边（verifying/referred 全链路、辅导员重开全量、复评 14+30 双默认强制）——未做须注明，不得假称 I1 结项
- 删改第①②批已验收主路径（仅叠状态机雏形、记录、复评、结案）
