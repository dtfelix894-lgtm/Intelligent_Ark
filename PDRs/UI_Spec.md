# 智伴方舟高校版 UI 规范

## 学生端

`/login` 是单页登录/注册表单。两种模式填写学号和密码，注册要求至少 6 位，已有短密码仍可登录；注册模式另有学校和学籍号可选字段。聊天页 `/chat` 为响应式栅格：宽屏（`lg`）左侧 260px 校园侧栏 + 中间对话区，超宽屏（`xl`）增加右侧 320px 自助工具栏；窄屏两侧栏收入左右抽屉，求助资源从侧栏/工具入口查看，不宣称所有宽度始终可见。

校园侧栏提供每日治愈，不含天气/距离考试状态。工具保留能量补给电台、正念放松站、学业解压锦囊、情绪碎纸机、木鱼、打字墙。`chat/components/EmotionShredder.tsx` 仍被现用工具引用。

输入区有 ASR 入口：授权→录音→识别→回填→学生确认发送，不自动发送。历史加载期间可编辑草稿但不能提交；历史失败可重载，发送失败恢复草稿。中文输入法确认选字不触发发送。

右上角为账户与预警设置，显示学校/学号及学姐/学长偏好；按账号保存在本浏览器，保存失败有明确提示。旧左下角设置不再是当前入口，Next 开发指示器已禁用。时间提示注明设备时间及月份推测，不冒充课表或学校校历。

## 工作端

`/admin-login` 只接受 G 类工号和密码，无注册入口。`/admin` 顶部三张概览卡为学生账号数、待跟进预警、数据范围，下方为预警池列表。卡片展示等级、脱敏摘要、标签和「标记已跟进」按钮。默认约每 3 秒轮询，设置可选 10/30 秒；红色优先开关控制排序，偏好按管理账号保存在本浏览器。状态以 API 为准，加载、空池和失败有不同反馈，失败提供重试。工作台未展示的趋势/活动 API 不视为已交付页面板块。

## 视觉与可访问性

当前默认浅色背景、白色卡片、紫色主色和绿色辅助色，以 `globals.css` 及现有组件为准。红色同时用于风险和错误/退出提示，不应误写为只表示高风险。已有 `.dark` 变量不代表提供了完整暗色主题或主题切换入口。

使用明确标签、焦点样式和键盘可操作按钮，风险不只通过颜色区分。现有自动化检查覆盖 375px、390px、横屏及桌面宽度；不等于完成屏幕阅读器、所有字号或实体手机适配认证。本阶段只对齐文档，不修改页面设计。
