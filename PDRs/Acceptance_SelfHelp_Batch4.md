# 自助工具第四批 · 验收标准

> 供 Ark 验收对照用。范围：PRD_v2 I2 剩余学生侧自助项——情绪日记（TOOL-02）、心理科普（TOOL-06）、人设偏好服务端保存（COMP-06）；可选落库项。叠在第一～三批 / 3.5 批之上。不写业务实现说明。遵守 docs/adr/。

## 清单

- [ ] **TOOL-02 情绪日记：可写一条、回看列表（非诊断文案）**  
  学生可写入一条自由文本日记并成功保存；可在列表中回看本人历史条目。界面文案**不**做诊断、不开药、不替代表业评估（对齐 SEC-04）。日记**不**进入风险判定 / 预警池（与 PRD TOOL-02 一致）。  
  **失败**：无法写入或无法回看；出现诊断式结论文案；日记触发风险入池。

- [ ] **TOOL-06 心理科普：至少 2 个分类、若干篇可打开阅读**  
  至少 **2** 个主题分类（如学业 / 睡眠 / 人际 / 情绪 / 求助等，等价即可）；每类或合计有若干篇短文可打开阅读。内容可为静态；须标注**来源或「演示」**（学校心理中心提供/审核或演示占位均可）。  
  **失败**：分类不足 2 个、无可读文章，或无来源/演示标注。

- [ ] **COMP-06 人设偏好服务端保存：换设备 / 清 local 后仍保留**  
  学生选择学姐 / 学长（或等价人设）后，偏好写入服务端；清空本地存储或换设备后**重新登录**，人设偏好仍与上次一致。本地存储失败时的现有降级提示可保留。  
  **失败**：仅存 local、清 local / 换端后偏好丢失或回默认。

## 可选验收项（做了才验）

- [ ] **打卡 / 量表 / CBT 结果可落库：本人可读、不入预警池**  
  若本批将情绪打卡、量表结果或 CBT 记录持久化到服务端：仅**本人**可读取回看；**不**写入预警池、不触发 RISK-05 入池。未做落库则本项跳过，不阻塞本批。  
  **失败**：他人可读，或落库结果进入预警池。

## 非目标（本批不验）

- RISK-05 量表/日记入池实现（可另写 ADR 草案，**本批不附、不验入池**）  
- 学院范围权限 / 越权（POOL-06 等）  
- 配置后台 ADM-03  
- 工作人员工作台 / 事件处置  
- 删除商业音频文件（仍需用户确认后再动）  
- 模型辅助判断 RISK-07  
- 不冲第一～三批 / 3.5 批已列项；不要求后台展示敏感原文（ADR 0002）
