# 管理员端第④批 · 验收标准

> 供 Ark 验收团队用。范围内：工作台 **匿名统计看板** + **审计日志页/面板** + **超时升级雏形** + **配置只读展示（env）** + 兼容①–③批。对齐 PRD_v2 **ADM-04 / ADM-05 / POOL-02 可落地子集 / ADM-02 只读展示**；脱敏遵守 ADR 0002。只写验收，不写业务实现说明。本批为管理员端连续 4 轮**末轮**。

## 清单

- [ ] **匿名统计看板（ADM-04 子集）：聚合指标，无账号/原文**  
  工作台概览或独立「匿名看板」区域/页签（心理中心与系统管理员可见）展示聚合指标，至少覆盖：**风险事件量**（可复用/并列 GET /api/admin/risk-trend）、**等级分布**、**跟进耗时分位或均值（如 P50/P90，有则验）或结案数**；有标签分布时可并列 GET /api/admin/risk-tags。看板**不展示**学生账号或任何个人可识别信息。加载中/空数据/失败均有反馈，失败可重试。  
  **失败**：看板露出账号或原文；无任何聚合指标；接口失败无提示。

- [ ] **小数抑制（尽量）：单维细分计数 <5 显示「<5」**  
  **尽量**做到：任一维度细分（如某标签×某等级、某结案标注计数等）原始计数小于 5 时，页面显示 **「<5」** 而非精确值（对齐 ADM-04 / SEC-02）。未做时须在交付说明标注「本批未做小数抑制」；做成则抽查至少一处 <5 场景。  
  **失败（仅当声称已做时）**：细分格子仍显示 1–4 精确人数/事件数。

- [ ] **审计日志页/面板（ADM-05 子集）：关键动作可查，无学生消息原文**  
  提供审计日志页或工作台内嵌面板，可按时间（及可选：操作者工号、动作类型）查看记录。至少覆盖本批及①–③已落地动作中的：**查看事件详情、认领、分派/改派、状态流转、结案、新增跟进记录**（有则记；系统动作可用 system）。字段含：操作者（工号或 system）、动作类型、对象（事件 ID）、时间、必要元数据。**不得写入**学生消息原文与密钥。日志只追加不改删；授权管理员可查看。  
  **失败**：无审计入口；上述关键动作完全无痕；日志含消息原文；可随意改删历史。

- [ ] **超时升级雏形（POOL-02 子集）：红/黄认领时限 + 超时标记/置顶 + 页头超时数**  
  认领时限来自配置（ADM-02 / env）：默认 **红 30 分钟、黄 24 小时**（可被 env 覆盖；prod 有下限则遵守）。仍为 pending 且超过时限的事件视为超时：列表/卡片可见 **「超时」** 标记或置顶；is_overdue（或等价）与超时时长可在列表/详情体现。工作台**页头**可显示当前超时数量。超时状态可在查询时计算，不强制后台定时任务；站外通知（短信/企微/邮件）本批不验。  
  **失败**：超时事件无任何区分；页头无超时数量入口；红/黄时限写死且无法被 env 覆盖说明；超时判定与配置明显不符。

- [ ] **配置只读展示（ADM-02 只读）：求助资源/时限等 env 摘要可见**  
  工作台可见当前配置**只读摘要**，至少包括：红/黄认领时限、求助资源要点（如心理中心电话、24h 危机热线等已配置项）。数据来自后端读取的 env / 现有配置接口，**本批不做 ADM-03 编辑页**；改配置仍走 .env。缺项时有明确「未配置」提示，不假装有虚构号码。  
  **失败**：工作台完全看不到时限/求助资源摘要；只读区可改写配置却无审计；缺配置时静默显示假号码。

- [ ] **兼容①–③批：筛选/认领/分派/状态机/复评/handle 不回归；学生端入池不变**  
  ①批：等级筛选（黄/红/全部）、待跟进/已跟进、红色优先、stats/trend/tags、POST .../handle（ction=follow_up）仍可用（含 legacy 结案映射）。②批：脱敏详情、学生分组（存储不去重）、认领（必）、分派（若已做）不回归。③批：状态流转、跟进记录、复评提醒、结案不回归。学生端 yellow/red 入池字段与工作台一致；green 不入池；详情/审计/看板均**不出现**消息原文（ADR 0002）。  
  **失败**：①–③任一主路径不可用；入池联通断裂；详情/审计/看板泄露原文。

## 本批不做（范围外）

- 完整配置编辑页 ADM-03（改配置仍走 .env；本批仅只读摘要）
- 管理员子角色精细权限 ADM-01；学院维度 POOL-06
- 量表入预警池（RISK-05 / 另 ADR）
- RISK-07 模型辅助
- 超时全量：站外通知链路、后台定时推送（POOL-02 通知部分）
- 删改①–③已验通的主路径（筛选/认领/分派/状态机/记录/复评/结案）
